Toasts – Feedback nach der Aktion

Kurze Rückmeldung, dass etwas passiert ist. Erscheint unten rechts, stapelt sich und blendet sich selbst wieder aus.

4 Varianten · Auto-Dismiss · manuell schließbar

Live-Test – Button anklicken, Toast erscheint unten rechts

Aufbau & Varianten (statisch)

Gespeichert

Werkzeug TS-1004 wurde aktualisiert.

×

Keine Verbindung zum Server. Bitte erneut versuchen.

×

TS-1004 ist seit 3 Tagen über der Wartungsfrist.

×
i

Synchronisiert

24 Werkzeuge vom Server übernommen.

×

Die Beispiele oben stehen im Layout, damit man das Aussehen ohne Klick sieht. In der App schweben sie als Overlay unten rechts und haben statt des ×-Zeichens einen echten Schließen-Button.

Variante Einsatz Dauer Auto-Dismiss
Erfolg Speichern, Ausleihe oder Rückgabe hat geklappt 4 s ja
Fehler Aktion fehlgeschlagen, der Nutzer muss etwas tun bleibt stehen nein, nur manuell
Warnung Hat geklappt, aber ein Zustand braucht Aufmerksamkeit (Wartung, Frist) 6 s ja
Info Ergebnis im Hintergrund (Sync, Import, Export) 4 s ja
✓
So einsetzen
  • Aktion und Toast zur selben Zeit, Text in der Vergangenheit: „Gespeichert“.
  • Höchstens 3 gleichzeitig, sonst wird die Seite verdeckt.
  • Immer Symbol und Text, nie nur die Farbe.
  • Der Fehlertext sagt, was jetzt zu tun ist.
×
Nicht so
  • Nicht als Rückfrage vor der Aktion, dafür ist das Modal da.
  • Nicht für Dinge, die man in der Tabelle ohnehin schon sieht.
  • Fehler-Toast nicht automatisch ausblenden, wenn er eine Handlung verlangt.
  • Keine langen Sätze und keine technischen Fehlercodes.
<!-- 1) Toast-Stack: einmal pro Seite, ganz unten im <body>.
     Wichtig: NICHT in .app-content-block legen – das hat
     transform/contain und würde position:fixed umlenken. -->
<div class="ui-toast-stack" aria-live="polite">
  <template x-for="t in toasts" :key="t.id">
    <div class="ui-toast"
         :class="'ui-toast-' + t.type + (t.leaving ? ' is-leaving' : '')"
         role="status">
      <span class="ui-toast-icon" aria-hidden="true" x-text="t.icon"></span>
      <div class="min-w-0 flex-1">
        <p class="ui-toast-title" x-text="t.title"></p>
        <p class="ui-toast-msg" x-text="t.message"></p>
      </div>
      <button class="ui-toast-close" @click="dismissToast(t.id)"
              aria-label="Toast schließen">&times;</button>
      <span class="ui-toast-life" x-show="t.duration > 0"
            :style="'animation-duration:' + t.duration + 'ms'"></span>
    </div>
  </template>
</div>

// 2) Toast-Objekt + Auslösen
const TOAST_ICON = { success: '✓', error: '×', warning: '!', info: 'i' };

pushToast(type, title, message, duration = 4000) {
  const id = ++this.toastSeq;
  this.toasts.push({
    id, type, icon: TOAST_ICON[type] || 'i',
    title, message, duration, leaving: false
  });
  if (duration > 0) setTimeout(() => this.dismissToast(id), duration);
}

pushToast('success', 'Gespeichert', 'Werkzeug TS-1004 wurde aktualisiert.');
pushToast('error', 'Speichern fehlgeschlagen',
          'Keine Verbindung zum Server. Bitte erneut versuchen.', 0);
// duration = 0  →  Toast bleibt stehen, bis er geschlossen wird

// zweiphasig: erst Austritts-Animation (.is-leaving), dann entfernen
dismissToast(id) {
  const toast = this.toasts.find(t => t.id === id);
  if (!toast || toast.leaving) return;
  toast.leaving = true;
  setTimeout(() => {
    this.toasts = this.toasts.filter(t => t.id !== id);
  }, 160);
}
