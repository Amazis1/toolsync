Lagerverschiebung – Interaktions-Demo

Reine Test-Datei (offline). Die echte App wird später genau so funktionieren, wenn du es hier gut findest.

Regeln in dieser Demo

  • Einreihen Neues Werkzeug aus der Ablage auf einen belegten Platz legen → alle Werkzeuge ab diesem Platz rücken um einen Platz weiter. Ist der letzte Platz belegt, wird die Aktion blockiert (es würde sonst ein Werkzeug verloren gehen).
  • Tausch Belegter Platz auf einen anderen belegten Platz ziehen → die beiden Werkzeuge tauschen sich. Nichts anderes rückt.
  • Verschieben Belegter Platz auf einen leeren Platz ziehen → Werkzeug wandert einfach hin.
  • Entfernen Werkzeug zurück in die Ablage ziehen → Platz wird frei (hilft beim Testen).

Werkzeug-Ablage – neue Werkzeuge, per Drag & Drop oder Klick auf einen Platz einreihen
